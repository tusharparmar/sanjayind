📋 Integration Methods

Method 1: Simple Script Tag

<script src="http://localhost:5000/widget.js"></script>
<script>
    new AIVoiceWidget({
        serverUrl: 'http://localhost:5000',
        theme: 'modern',
        position: 'bottom-right'
    });
</script>

Method 2: Auto-initialization

<script>
    window.aiVoiceWidgetConfig = {
        serverUrl: 'http://localhost:5000',
        theme: 'modern',
        position: 'bottom-right',
        autoConnect: true
    };
</script>
<script src="http://localhost:5000/widget.js"></script>

Method 3: iframe Embedding

<iframe 
    src="http://localhost:5000/widget?theme=modern&position=bottom-right"
    width="320" 
    height="500"
    frameborder="0">
</iframe>

🔌 API Integration

You can also interact with the AI assistant programmatically:

// Send a text query
fetch('/api/ai-query', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        query: 'How do I reset my password?',
        context: {
            url: window.location.href,
            pageText: document.body.innerText
        }
    })
})
.then(response => response.json())
.then(data => console.log(data.response));
